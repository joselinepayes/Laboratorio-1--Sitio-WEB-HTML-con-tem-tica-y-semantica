# Laboratorio 1 - Sitio Web HTML

## Descripción
Este repositorio contiene el código fuente y los recursos del primer laboratorio del curso de **Desarrollo Web**. El proyecto consiste en la estructuración de una página web estática utilizando HTML. 

El sitio implementa las siguientes características:
* Estructura básica del documento HTML.
* Menú de navegación.
* Diseño de una tabla de integrantes.
* Inserción de múltiples imágenes de personajes.
* Formulario semántico para el registro de visitantes.

## Tecnologías Utilizadas
* **HTML5:** Para la estructura y semántica del contenido.
* **CSS:** Aplicación de atributos básicos y clases (como `.boton-registro`).

## Estructura del Directorio
- `index.html`: Archivo principal con todo el código fuente de la página.
- `img/`: Directorio que almacena todas las imágenes estáticas mostradas en el sitio.
